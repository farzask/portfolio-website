🆘 TROUBLESHOOTING

Issue: Styles not showing
  Fix: rm -rf .next && npm run dev

Issue: Module not found
  Fix: npm install

Issue: Port already in use
  Fix: npm run dev -- -p 3001

Issue: Git issues
  Fix: Files already committed. Start with: git add . && git commit -m "message"
